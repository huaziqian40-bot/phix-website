怎么安装

不同平台的安装方式略有差异，按你的平台对照操作即可。装之前建议先看一眼下方「文件校验」，确认下载完整。

  1. 1

    Windows 安装版（.exe）

    双击安装包，按向导完成安装。如果系统弹出「未知发布者」提示，先核对文件大小与 SHA-256，再决定是否继续（见「常见问题」第一条）。

  2. 2

    Windows 免安装版（.zip）

    解压到任意目录后直接运行主程序。免安装版不会往系统里装东西，也不需要管理员权限；卸载时删掉这个文件夹即可（本地数据文件另见「卸载与数据」）。

  3. 3

    macOS（.dmg）

    打开 dmg，把应用拖入「应用程序」，再在「应用程序」里启动。首次打开若提示「无法验证开发者」，同样先核对校验值，再在访达里右键选择「打开」。

  4. 4

    Android（.apk）

    允许「安装未知来源应用」，然后安装并首次启动登录。不同机型的设置入口略有差异。

安装版还是免安装版？

目前只有心履 Windows 端同时提供两种形式，其余平台都只有安装版。按你的使用习惯挑一个就行，功能上两者没有区别。

对比项安装版（.exe / .dmg / .apk）免安装版（.zip）
怎么用双击安装包，按向导装到系统里解压到任意目录，直接运行主程序
入口开始菜单、桌面快捷方式（macOS 在「应用程序」里）自己记住解压目录，可自己建快捷方式
对系统的影响写入安装目录与卸载信息，需要时可从系统里卸载不写注册表、不动系统，解压即用
卸载走系统的卸载入口（Windows「应用和功能」／macOS 拖进废纸篓）删掉解压出来的文件夹即可

两种形式的本地数据目录与保存位置相同，卸载时是否保留这些文件见下方「卸载与数据」。

卸载与数据

卸载程序只负责移除应用本身，你的本地记录与配置是另一回事，请按下面的顺序处理。

  • 应用文件：安装版走系统卸载入口（Windows「设置 → 应用 → 已安装的应用」，或开始菜单里的卸载项；macOS 把「应用程序」里的应用拖进废纸篓）。免安装版删掉解压出来的文件夹即可，不需要卸载程序。
  • 本地记录与配置：日程、心情、课表、账号与界面偏好等保存在本机的数据目录里，卸载应用不等于删除它们。该目录的具体位置、以及卸载时是否保留，以安装包内说明为准（不同版本可能不同，本页不做笼统承诺）。想彻底清掉本机痕迹，请在卸载后按该说明手动删除这个数据目录。
  • 云端数据：同步到云端的对象是密文，它们不会因为卸载客户端而消失。需要删除时，请在账号里操作——官网个人中心或客户端的同步设置里删除对应对象（日程 / 心情 / 课表 / 头像等），删除后服务端才会真正移除该密文对象。
  • 备份建议：客户端支持本地保存与云端同步；重要内容建议定期备份，别只依赖单一设备或单一云端副本。
  • 密码与恢复码：云端数据是端到端加密的，如果登录口令和注册时的一次性恢复码都丢失，云端数据将无法解开。请把恢复码单独保存好。

常见问题

Windows 提示「未知发布者」、macOS 提示「已损坏 / 无法验证开发者」怎么办？

别急着点「仍要运行」，按顺序判断：① 先核对文件大小与本页「文件校验」里的 SHA-256 是否一致；② 如果哈希对得上，说明文件本身完整，系统仍然拦截，多半是因为安装包没有购买代码签名证书——确认文件确实来自本页后，再选择「仍要运行」（macOS 在访达里右键应用选「打开」，或到「系统设置 → 隐私与安全性」允许）；③ 如果哈希对不上，说明下载过程中出了问题，请删掉文件重新下载，不要安装。

安装版和免安装版怎么选？

功能一样，只是装法不同。想长期用、希望有开始菜单和桌面图标，选安装版；想解压就能用、不往系统里装东西（机房、公共电脑、临时试用），选免安装版。详见上方「安装版还是免安装版？」对比表。

怎么确认文件没有下载损坏？

见上方「文件校验」：用 certutil（Windows）或 shasum -a 256（macOS / Linux）算一遍，和页面上的 SHA-256 以及随版本发布的 checksums.txt 比对，一致就没问题。

三个产品的安装包要分别下载吗？

是三个相互独立的产品，按你要用的那个下就行：心履（心情记录 + 日程提醒，四端跨设备同步）、Pinghe Launcher（课表 / 作业 / 邮箱 / AI 的桌面中枢）、Pinghe Launcher Lite（轻量的日程助手，可与 Pinghe Launcher 共用本地数据）。不确定选哪个，可以去产品页看功能对比。

卸载之后我的数据还在吗？

分两部分看：本机的数据目录是否随卸载保留，以安装包内说明为准；云端的密文对象不会因为卸载而删除，需要在账号里手动删除。详见上方「卸载与数据」。
