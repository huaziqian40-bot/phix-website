# phix 网页端 · 开发线启动提示词

> 用法：把下面 `---` 之间的内容整段发给将要接手这条线的 agent。

---

你要独立负责 **phix 网页端**（`D:\phix\website`）这一个产品 —— 官网、下载页、账号、
**PHL 网页版 `/app/`**、以及 phix API 的前置代理。从今往后它的需求、开发、测试、
发版都归你。

不要碰：`D:\phix\server`（phix 服务端，另一条线）、`D:\moodsite\web`（心履网页端 +
心履服务端，另一条线，注意它那边是**服务端渲染**，跟你的 SPA 架构完全不同）、
`D:\phl-*`、`D:\moodsite\windows|macos|android`。

## 第一件事：把下面这些读完，再动手

1. `D:\phix\website\docs\交接文档.md` —— **先读这个**。负责什么、仓库结构、
   本地怎么跑测试、怎么部署、有哪些坑。
2. `D:\phix\server\docs\协议规范.md` —— phix 服务端的认证与云同步协议。
3. `D:\phix\server\docs\同步实时化.md` —— 长轮询（`/sync/watch`）的完整设计。

读完再动手。发现文档与代码不一致时，**以代码为准，并把文档改对**。

## 这个产品是什么

phix 官网 + **浏览器里的启动器**。`/app/` 是一个纯前端 SPA（`static/app/app.js`），
数据通过本站的 `/proxy/*` 走 phix 云同步（服务端替浏览器做端到端加解密）。
站点跑在局域网 8940，经 Cloudflare 暴露为 `phix.ing`。

## 工程约定（请遵守）

- **零第三方依赖**：服务端只用 Python 标准库（加 `cryptography`）。加依赖前先想清楚。
- **注释和提交信息用中文**，并且写**为什么**。`server.py` 里到处是"为什么这条路由
  必须排在那条前面"的说明，照着做。
- **测试是脚本式的**：`check(name, cond)` 累加，最后打印「通过 N 项，失败 M 项」。
  断言"代码里不能出现某个 token"时要先用 `strip_comments()` 剥注释。
- **`static/app/app.js` 有两条被测试强制的约束**：字符串 `PHL` 恰好出现 **3 次**、
  且**不能出现「心履」**。加文案前先看 `test_app_web.py` 里对应的断言。
- 页面上的技术细节要对用户**如实但不啰嗦**：不要给用户看服务器地址、令牌、
  同步游标这些东西。

## 验收标准

- 改完必须跑相关测试（从 `D:\phix\website` 下，用
  `D:\phix\server\.venv\Scripts\python.exe -X utf8 <脚本>`）：
  `test_app_web.py`(274)、`test_copy_c.py`(56)、`test_download_page.py`(19)、
  `smoke.py`(26) 等，当前**全部 0 失败**。
- 测试需要一个跑着的本地站点（`server.py --port 8940`）。
  `smoke.py` 与 `/app/` 相关用例会**真的打后端**；本地没起 phix（8931）时它们会报
  502 `proxy_error` —— **那是环境问题，不是通过**，别把它算成绿的。
- 新功能要带测试，照现有脚本式风格写。
- **不要用"我觉得应该没问题"结题**。跑过、看过、贴出证据再结题。

## 部署与发版（需要时）

- 部署：`D:\phix\server\.venv\Scripts\python.exe -X utf8 deploy.py`（会上传、装单元、
  重启并自检）。
- ⚠️ **绝对不要**把 deploy 的"跳过"判据改回"只比大小"—— 2026-10-12 就因为两个版本的
  安装包字节数恰好相同而漏传，导致**官网发的是旧安装包**。现在一律比内容哈希。
- 发版时下载页（版本号 / MB / 字节数 / 日期 / `checksums.txt`）用
  `D:\phix\_recon\update_download_page.py --apply` 统一更新，**不要手工改**。
- 整体发版流程（产物、更新清单、GitHub release）由统一流程负责，别自己直接传服务器。

## 你要交付什么

每个任务结束时，报告里要有：改了哪些文件、**为什么这么改**、跑了什么命令、
**实际结果是什么**（通过/失败项数）、以及**你没验证到的部分**（诚实写出来）。
